# UI spec

Style: clean interface, vivid colors per category, as few taps as possible. Native components where
they matter (tab bar, sheets, Liquid Glass on iOS 26), custom elsewhere.

## Navigation

```
Root stack
├── (tabs)
│   ├── Home            /                 donut + −/+ buttons
│   ├── Transactions    /transactions     list by category, search
│   ├── Stats           /stats            summary, chart, ranking, budgets
│   └── Settings        /settings
├── transaction/new     (modal)           ?type=expense|income&categoryId=
├── transaction/[id]    (modal)           edit
├── transfer/new        (modal)
├── category/…, account/…, budget/[id], recurring/…   management screens
├── period, currency, language, month-start, export, account/select, whats-new   (sheets)
└── onboarding          (full screen, first launch)
```

## Home

```
┌───────────────────────────────┐
│  All accounts ▾          ⇄    │
│  Day Week Month Year All      │
│   ◀   September 2026   ▶      │  ← horizontal swipe changes the period
│                               │
│  🍎      🏠      🚌      🎁   │  ← category icons (tap = add an expense there)
│      ╭───────────────╮        │
│  💊  │   Balance     │  🎬    │

│      ╰───────────────╯        │
│  🐶      📱      🚕      …    │
│                               │
```

- Tap the center of the donut → cycles Balance / Expenses / Income.
- Tap a slice → transactions list opened on that category.

## Adding a transaction (modal)

```
┌───────────────────────────────┐
│ ✕   Expense        💳 Cash    │
│                               │
│                    € 12.50    │  ← amount / expression
│ 📝 Add note…  [Done] │ ↻ Repeat│
│ Today  Yesterday  📅          │  ← future dates allowed
│ ┌─────┬─────┬─────┬─────┐     │
│ │  7  │  8  │  9  │  ÷  │     │
│ │  4  │  5  │  6  │  ×  │     │
│ │  1  │  2  │  3  │  −  │     │
│ │  .  │  0  │  ⌫  │  +  │     │
│ └─────┴─────┴─────┴─────┘     │
│ [ Choose category ]           │  ← "Save" if a category is already chosen
└───────────────────────────────┘
```

- Coming from a category icon on the home screen → category preselected, the button says "Save".
- Otherwise the category grid opens after the amount; tapping a category saves.
- "Repeat" cycles weekly / every 2 weeks / monthly / yearly and creates a recurring rule.

## Transactions list

- Grouped by category with total and count; tap to expand (50 rows at a time, "Show more").
- Search by note or category shows results grouped by day.
- Swipe left past half the width → delete with haptic feedback and "Undo" (4 s).
- Tap → edit; ↻ marks transactions generated by a recurring rule.
